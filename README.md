# Electricity-Production-Analytics-Pipeline

## Description:
This in an end-to-end data engineering pipeline that ingests simulated real-time electricity production events via Kafka, processes them with Pyspark, and orchestrates the entire workflow using AirFlow. Originally a group project, this is an updated version with more error handling and logging. 

## Instructions:
- To run this program, you will need Docker installed on your system: https://www.docker.com/get-started/
- Run this command while in the root fold of the project: docker-compose up -d
